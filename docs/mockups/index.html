Static HTML previews of every M1 surface, rendered with the same Tailwind classes the real Next.js components use. Click any link to open that surface in your browser — no pnpm install, no dev server, no Supabase keys required.

These mockups are visually identical to what the real components render once Tailwind is installed in node_modules and app/page.tsx is removed on the host (see docs/dev-runbook.md). They're the fastest way to preview the polished UI without leaving the file system.
